# TIP103 Interview Prep

A collection of coding interview practice problems and solutions completed throughout TIP103.

This repository is used to track progress, reinforce problem-solving patterns, and build consistency with common data structures and algorithms.

## Topics

- Arrays & Strings
- Hash Maps / Sets
- 2D Arrays
- Two Pointers
- Sliding Window
- Stacks & Queues
- Trees & Graphs
- Recursion
- Dynamic Programming
- Other interview-style problems
